# docs/hermes/

Esta pasta contém relatórios de verificação e auditoria gerados por sessões de IA externas (Hermes Agent — SolarPro4, LongCat, etc.) ao longo do desenvolvimento do projeto `planet9-screening-lab`.

**Finalidade:** material probatório de trabalho — evidencia o que foi revisado, quais decisões foram tomadas e por quê.

**Aviso:** cada documento aqui deve ser lido com o mesmo ceticismo aplicado a qualquer relatório interno do projeto. São instantâneos de um estado em um dado momento, sujeitos a:
- incompletude (o que não foi visto pode existir),
- erro (IA interpreta mal código, omite contexto, alucina fatos),
- viés de confirmação (a IA tende a concordar com premissas dadas).

**Convenção:**
- Nome do arquivo: `<data>_<hora>_<contexto>.txt` (ou `.md`).
- Fonte é indicada no cabeçalho de cada documento.
- Documentos aqui NÃO são fonte de verdade — o código-fonte e os testes (`tests/`) são.
